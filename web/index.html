Import & chunk

Extract PDF text page by page. Split into 120-word chunks with 25-word overlap. Keep document_id and page for every chunk.

02

Embed & retrieve

A local BGE encoder produces 384-dimensional vectors for cosine search. Compare with BM25 and reciprocal rank fusion.

embeddings.py · retrieval.py
03

Ground & generate

Extract exact source text by default, or select local Qwen to synthesise an answer from retrieved passages.

paperlens/answer.py
04

Evaluate & improve

Measure Hit@K, MRR and page recall. Review whether evidence supports each answer and retain failure cases.

evaluate.py · eval_cases.json

Start with three experiments

  1. Ask a question whose answer you know. Open the cited PDF page and check each claim.
  2. Rephrase the question using synonyms. Compare BM25 and vector rankings.
  3. Change chunk length, build a separate index and compare results. Test whether hybrid retrieval actually helps.
